# Роксолана · 25

A birthday "wallpaper" for the living-room TV.

- **Before midnight:** dark aurora (black · green · purple · burgundy), peonies & lilies, a live clock, a spinning record.
- **23:59:00 on 3 November:** a 60-second countdown with a ring. In the last 10 seconds it says *загадай бажання* ("make a wish").
- **00:00:** a flash, fireworks (some heart-shaped), "З днем народження, Роксолано", a big 25, polaroids, falling petals and rotating quotes. It stays like this for the whole day.

## Controls

| | |
|---|---|
| **Test** button (bottom-left, fades out when the mouse is idle) or `T` | Starts the 60 s countdown now |
| `Shift+T` | Countdown from 10 s |
| `C` | Skip straight to the celebration |
| `F` / double-click / ⛶ | Fullscreen |
| `R` / `Esc` | Back to real time |

URL options: `?test`, `?test=10`, `?celebrate`, `?daily` (the countdown runs every night at 23:59).

## Editing

Everything personal is in `config.js`: name, date, photos + captions, and quotes.
To add a photo, drop it into `assets/photos/` and add a line to `PHOTOS`. Portrait (4:5) photos fit the polaroids best.

## On the night

1. Open the site in a browser on the TV (or on a laptop over HDMI), press `F` for fullscreen and leave the mouse alone.
2. Turn off the TV's screensaver/eco-dimming. The page also asks the browser to keep the screen awake.
3. The countdown starts on its own at 23:59:00 **by the device's clock**, so check that clock first.
