Відкрити photos.js на GitHub ↗
Як змінити назви:
  1. Змініть підписи під фото тут (зміни зберігаються в цьому браузері, жовті картки = змінені). Зніміть «показувати», щоб прибрати фото з показу.
  2. Натисніть Скопіювати photos.js.
  3. Натисніть Відкрити photos.js на GitHub → виділіть усе (Ctrl/⌘+A) → вставте → Commit changes. Сайт оновиться сам за 1–2 хв.
